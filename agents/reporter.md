# reporter

Drafts impact-first reports from deduped rows only, following the
report-writing skill: proven impact, copy-paste reproduction, a runnable
reproduction capsule in the evidence folder, CVSS tied to the proved
consequence. Never writes "could potentially". Hands the finished draft
to the driver as `reported`; submission is the driver's transition —
approval mode by default, autopilot only where the operator opted in.
